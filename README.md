# ModForge Studio

**Локальная мастерская для авторов игровых модов:** импортируйте исходники, проверьте состав пакета, зависимости и пересечения, соберите профиль коллекции и подготовьте ZIP-релиз. Файлы обрабатываются в браузере и не отправляются на сервер.

> Экспериментальная версия 0.1.1. Проверяйте результат вручную перед публикацией: правила эвристические и не заменяют тестирование игры.

## Возможности

- Импорт каталогов с сохранением относительных путей, отдельных файлов и ZIP.
- Распознавание Paradox/Clausewitz, Factorio, RimWorld, Fabric, Forge и SMAPI по манифестам.
- Проверки отсутствующего описания, пустых архивов, подозрительных исполняемых файлов, лишних вложенных архивов, дубликатов, конфликтов регистра и типовых секретов.
- Граф зависимостей с поиском отсутствующих модов, циклов и рекомендуемым порядком загрузки.
- Сравнение конфликтующих путей между модами, профили включённых модов и локальный каталог в IndexedDB.
- Экспорт отчёта JSON, профиля JSON и нового ZIP-архива без загрузки исходников в облако.

## Запуск

Нужен Node.js 20+ только для локального статического сервера. Сборка и зависимости npm не нужны. Приложение также можно установить как PWA из браузера; после первого открытия интерфейс доступен без сети.

```sh
npm run serve
```

Откройте адрес, напечатанный сервером. Не открывайте `index.html` через `file://`: модульные скрипты и хранилище браузера требуют HTTP(S).

Для тестов ядра:

```sh
npm test
```

Тесты распаковки сжатого ZIP требуют Node.js 20.12 или новее.

## Использование

1. Нажмите **Добавить моды** и выберите папку, несколько файлов или ZIP. ZIP разбирается локально; поддерживаются методы store и deflate.
2. Откройте карточку результата, разберите предупреждения и отсутствующие зависимости.
3. В разделе **Профиль** включите нужные моды. Неразрешённые зависимости и циклы выделяются.
4. Скачайте JSON-отчёт либо соберите ZIP из выбранного профиля. При сборке скачиваются архив и отдельный файл `.sha256` для сверки целостности.

Для проверки нескольких модов из папок импортируйте все папки одним действием. У ZIP-архивов автоматически удаляется общая верхняя папка-обёртка только если она единая и содержит содержимое мода.

## Поддерживаемые метаданные

| Экосистема | Файл | Читаемые поля |
| --- | --- | --- |
| Paradox / Clausewitz | `descriptor.mod`, `*.mod` | name, version, dependencies, tags |
| Factorio | `info.json` | name, version, dependencies |
| RimWorld | `About/About.xml` | name, packageId, supportedVersions, dependencies |
| Minecraft Fabric | `fabric.mod.json` | id, version, depends |
| Minecraft Forge | `META-INF/mods.toml` | modId, version, dependencies |
| Stardew Valley SMAPI | `manifest.json` | Name, UniqueID, Version, Dependencies |

Форматы игровых бинарников не проверяются: `.pak`, `.dll`, `.jar` и подобные файлы лишь инвентаризируются.

## Ограничения и приватность

- Это браузерное приложение, не менеджер установки: оно не изменяет папки игры и не загружает файлы в Steam Workshop.
- Данные коллекции сохраняются в IndexedDB текущего браузерного профиля. Удалить локальную базу можно через настройки хранения сайта в браузере.
- ZIP ограничен 500 МиБ распакованного содержимого и 20 000 записей. Зашифрованные ZIP не поддерживаются; ссылки, абсолютные пути и traversal-записи исключаются.
- Размер распаковки проверяется по фактически прочитанным данным, а не только по полю размера внутри ZIP. Файл, который распаковывается больше заявленного размера, отклоняется.
- Поиск секретов ловит распространённые шаблоны и может давать пропуски/ложные срабатывания. Просмотрите найденный текст до экспорта.
- Авторские права, лицензии, зависимости и совместимость проверяйте по первоисточникам.

## Разработка

Проект — ES-модули без сторонних runtime-зависимостей. Ядро находится в `src/core`, интерфейс — в `src/ui`, схема IndexedDB — в `src/storage`, тесты — в `tests`.

```sh
npm run check
```
